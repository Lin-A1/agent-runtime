# ZCode vs newhorse 功能缺口对照报告

> 2026-09-01。方法：ZCode i18n 5000 键逐条分类 + newhorse UI 全量代码审读。按用户面功能（非内部实现）对照，跳过 IM 机器人/账号/套餐/插件市场/git 集成。

详细报告见本文件以下内容。核心发现：

## 顶层结论

- **已对齐**：约 28 个功能面（供应商管理/会话列表/变更卡/todo/goal/子代理/文件树/审批/记忆/定时/用量/命令面板/@提及/图片/通知/远程等）
- **newhorse 独有差异点**：DAG 编排页、运行时目录、类型化记忆、webhook 渠道、常驻会话情绪球、转录导出、DAG 投影 todo、LAN/token 自托管、每轮模型调用轨迹
- **缺口**：约 45 项，分三档

## P0 缺口（核心聊天体验，影响日常使用）

| 缺口 | 描述 | 工作量 |
|---|---|---|
| 检查点回退 | 每轮"撤销/重新应用"文件变更 + 外部修改检测（安全/不安全/忽略分类） | L |
| 计划模式 + 计划审批 | readonly 策略存在但无结构化计划面板/审批流程 | L |
| 富权限提示 | allow 一次/总是/会话/项目、命令前缀 vs 精确、文件变更摘要、键盘驱动 | M |
| 子代理画像 CRUD | 用户级子代理 markdown 配置（名称/模型/工具/系统提示/开关/删除） | M |

## P1 缺口（重要）

| 缺口 | 描述 | 工作量 |
|---|---|---|
| 结构化问答（AskUserQuestion） | 多问题对话框 + 选项 + 自定义回答 + 倒计时 | M |
| 编辑用户消息 & 重发 | 编辑已发消息 + 重试 + 恢复 | M |
| 上下文分解详情 | messages/system/skills/tool prompts/MCP 分列 + 缓存命中率 | M |
| 队列管理 | 拖拽排序/编辑/移除/暂停恢复/确认对话框 | M |
| 工具调用分组 & 详情 | 终端组/文件组/搜索组/状态/MCP 详情/截断输出分页 | M |
| 子代理目录（含已结束 + 转录） | 运行+已结束列表 + 展开子会话转录 | M |
| 跨代理消息 UI | sendMessage 渲染 + 邮箱 + 来源徽章 | M |
| 技能/命令管理 | 每技能开关/scope/搜索/删除 | S |
| MCP 创建/编辑表单 | 完整表单（stdio/SSE/超时/协议版本） | S |
| 外观设置 | 主题/UI 字号/行号/换行/工具分组展示 | S |
| 文件通知矩阵 | 等待审批/需输入/错误/计划审批 | S |
| 任意文件附件 | 非图片附件（引擎暂缺，plan: 附件 API wave 2） | M |

## P2 缺口（锦上添花）

提示润色/建议草稿/预览卡/大消息分页/消息操作/目标验证循环/模型切换守卫/语言切换/通用设置/索引/Wiki/浏览器面板/CUA/SSH/反馈/完整轨迹查看器/闲时任务/自动更新

## newhorse 差异点（ZCode 没有）

DAG 编排页、运行时目录、类型化记忆+手动写入、webhook 渠道、常驻会话+情绪球、转录导出 MD、DAG 投影 todo+goal 预算条、LAN/token 自托管+二维码、Fork 首页按钮、每轮模型调用轨迹内联
